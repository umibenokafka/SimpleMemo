# SimpleMemo
SwiftUIを用いて作成したシンプルなメモアプリです。

Features

メモ追加

メモ表示

メモ編集

メモ削除

UserDefaultsによるデータ保存

Technologies

Swift

SwiftUI

UserDefaults

Git / GitHub

CRUD

Create（追加）

Read（表示）

Update（編集）

Delete（削除）

Overview

入力したメモを一覧表示し、タップで編集、スワイプで削除できます。データはUserDefaultsに保存されるため、アプリを再起動しても保持されます。
